# 🎯 Guess The Number

A simple and interactive **Number Guessing Game** built using Python. The computer generates a random number, and the player has to guess the correct number.

## 📌 About the Project

Guess The Number is a beginner-friendly Python project designed to demonstrate basic programming concepts such as random number generation, conditional statements, loops, and user input handling.

The objective is to guess the number selected by the computer.

## ✨ Features

- Random number generation.
- Interactive user input.
- Simple and easy-to-understand gameplay.
- Instant feedback on guesses.
- Beginner-friendly Python implementation.

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** Random

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/SOUHARDGUPTA/Guess-The-Number.git
```

### 2. Navigate to the Project Directory

```bash
cd Guess-The-Number
```

### 3. Run the Python File

```bash
python guess_the_number.py
```

## 🎮 How to Play

1. Run the Python program.
2. The computer selects a random number.
3. Enter your guessed number.
4. Follow the feedback provided by the program.
5. Keep guessing until you find the correct number!
